# 빵밭 (BBANGBAT)

빵밭은 대전 빵지순례자를 위한 실시간 빵집 현장정보 서비스입니다.

방문하기 전에는 알기 어려웠던 혼잡도와 현장 소식을 사용자들이 함께 나누어, 기다림과 헛걸음을 줄이고 더 즐거운 빵지순례를 돕습니다.

## 핵심 기능

### 지도 기반 빵집 탐색

현재 위치를 기준으로 주변의 대전 빵집을 가까운 순서로 확인하고, 지도와 검색을 통해 원하는 빵집을 빠르게 찾을 수 있습니다.

### 실시간 혼잡도

가게 근처의 사용자가 `여유`, `보통`, `혼잡`으로 현장 상황을 제보합니다. 최근 참여 결과를 바탕으로 지금 방문하기 좋은지 확인할 수 있습니다.

### 실시간 톡과 AI 요약

대기 시간, 빵 재고, 주차 상황처럼 방문에 필요한 소식을 빵집별 실시간 톡으로 공유합니다. 여러 제보는 AI가 한눈에 알아볼 수 있도록 요약합니다.

### 나만의 빵지도

관심 있는 빵집을 즐겨찾기로 저장하고, 다시 방문하고 싶은 장소를 한곳에서 관리할 수 있습니다.

### 빵명록

구매한 빵과 사진, 별점, 후기를 기록합니다. 다른 빵친구의 기록을 참고해 다음 빵지순례 코스를 정할 수 있습니다.

### 소셜 로그인과 내 활동

카카오와 네이버 계정으로 간편하게 시작하고, 작성한 빵명록과 즐겨찾기, 실시간 톡 활동을 확인할 수 있습니다.
